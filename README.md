## 哪些人不用买这些

只跑一个静态博客、一个探针、一个 Telegram bot，1 GB 档足够，$21.99 一年，不用上 4 GB。

需要 cPanel 面板、要别人帮你建站管站，应该去看虚拟主机或者分销主机，不是 VPS 特价。VPS 给你的是 root 和一整套要自己配的环境。

不能接受自己管系统的人也别买。unmanaged 意味着系统崩了、服务起不来、磁盘满了，第一责任人是登录 SSH 的那个人。
